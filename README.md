# Scripting

供 iOS Scripting App 使用的脚本集合。

## 水印工具箱

位于 [`scripts/水印工具箱`](scripts/水印工具箱)，提供以下功能：

- 从分享内容或网页链接识别可访问的图片、视频和音频资源。
- 保存媒体到系统照片或文件，管理下载任务。
- 为照片添加自定义文字水印。
- 对支持的媒体生成实况照片，并可选择本地音频。
- 提供分享菜单、Safari 入口、小组件和下载实时活动相关脚本。

识别与保存能力受来源页面、访问权限、网络及媒体格式影响，不保证所有链接均可用。

## 安装

1. 在 iPhone 或 iPad 上安装并更新 Scripting App。
2. 下载本仓库源码并解压。
3. 将 `scripts/水印工具箱` **整个文件夹**复制到 Scripting 的脚本目录（如 iCloud Drive → Scripting → scripts），保留所有子目录及文件。
4. 在 Scripting 中打开“水印工具箱”运行；若未出现，检查 `script.json` 与 `index.tsx` 是否直接位于该脚本文件夹下。

本项目依赖 Scripting 的原生 API、Python 与媒体处理运行环境，不能直接作为 Node.js 程序或普通网页运行。遇到 API 不可用时请先更新 App。可选解析组件按界面提示安装，组件不包含在仓库内。

## 使用

- **解析与保存**：粘贴完整分享内容或网页链接，发起解析，按资源类型选择保存位置。
- **照片水印**：选择照片，设置文字及显示效果，预览后保存。
- **实况照片**：对支持的资源选择保存实况照片；没有原音轨时可使用本地音频。
- **扩展组件**：在设置中安装、更新或移除。下载需访问第三方软件分发服务，并遵守其许可。
- **分享入口**：在系统分享菜单中将文本或链接交给 Scripting；Safari 和小组件入口还需在 App 或系统中启用相应功能。
